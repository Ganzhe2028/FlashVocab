闪词 开始背单词

使用说明

闪词怎么用：把老师发的单词表变成三分钟练习

闪词是一个在浏览器里背单词的网页，为「老师今天发了单词表，明天就考」这种场景做的。下面这份说明讲清楚它在哪些情况下好用、词表怎么放进来、背的时候按什么键，以及数据存在哪里。

闪词适合什么场景

临时小测通常长这样：老师发一份 Word 或 Excel，二三十个词，明天上课默写，考完这一组基本就不再碰。用完整的学习 App 背太重，用纸背又记不住哪些词错过。

闪词只做这一件事：你把这份词表放进去，它排好一次能背完的练习；考完把这一组收起来，期末再一起复习。适合这些情况：

  • 课堂临时小测、默写，词表只有二三十个词。
  • 每学期积累了好几份词表，想按词表分组复习。
  • 不想注册账号、不想装 App，打开网页就想开始。
  • 习惯用键盘过词，一个词两三个键。

三步把词表放进来

第一次打开闪词是三步向导，每一步只做一个决定。

1 放入

选「文件」或「粘贴」：文件必须是 .json，粘贴必须是纯 JSON 数组。页面上可以下载 JSON 模板；如果手上的材料是 Word、Excel、Markdown 或 PDF，点「把其他格式转成 JSON」，复制提示词交给任意 AI 转换，再把结果粘回来。

2 核对

先看一眼识别结果：多少个词、多少个有中文释义、前五个词长什么样。有词缺资料时，这一页会多出一行「N 个词还没补全资料 · 让 AI 补全」。补全是可选项，不补也能直接开始背。

3 开始

确认后点「开始背这 N 个词」，直接进入认词，不用再点一次确认。

词表格式：一个 JSON 数组

闪词的导入边界只接受一个纯 JSON 数组，不带代码围栏、说明文字或包装对象。每个词条必须有 term，并且 meaning（英文释义）和 meaningZh（中文释义）至少填一个。

可选的字段包括词性、音节、注音、词源、对应词、例句和练习情景。例句写成 { "sentence": "...", "focus": "..." }，其中 focus 必须原样出现在 sentence 里，它决定认词页高亮哪个搭配。

字段名必须用模板里的写法：term、meaning、meaningZh 等。写成 word、definition 这类别名会被拒绝，并指出是第几个词条。格式错误时整批不导入，不会悄悄丢词。

页面提供固定模板和「把其他格式转成 JSON」的提示词，照着填或者交给 AI 转都可以。模板下载、字段校验和提示词都在导入页第 1 步。

背的时候手不用离开键盘

认词页只问一件事：这个词你认不认识。按 Q 或 E 都会展开答案——中文释义用大字在上，英英释义用小字在下，再下面是例句，词源和对应概念折叠着，想看再点。先判断再看答案，比一上来就读释义有效。

认词和拼写阶段的常用键位。
按键作用
Q认识
E不认识
N看答案之后：下一个
M选错了，把这次判断改判成不认识
←回看上一个词
Delete / Backspace把这个词移出当前词表
Esc暂停拼写

拼写阶段用真实的输入框：提交空答案或答错会记一次不认识并清空输入，需要重新打对。练习阶段用数字键选答案，N 进入下一题。

答错的词会自己回来

  • 第一遍标「不认识」的词，这一轮里会多考两次，通常隔三张卡再出现。
  • 同一个词连续两轮都答对，会歇一整轮（下一轮先不出现），再下一轮回来；回来还答对就继续歇，答错就回到正常队列。
  • 连续三次独立答对，这个词毕业，从认词里消失。毕业的词还能在词表里找回来。

每一轮结束会有一张结算页，分开统计你第一次判断里认识和不认识的词，以及掌握度的分布。结算页可以直接继续下一轮，也可以进入专项练习。

结算页和四种专项练习

专项练习从结算页或词表面板的「专项练习」进入，共有四种：

  • 看释义选词：给出中文或英文释义，从几个词里选出对应的那个。
  • 看情景选词：给一句英文情景，选出最合适的词。
  • 填搭配：补全例句里的重点搭配。
  • 辨析近义词：在容易混的一对词里，按情景选出正确的那个。

题目在进入时才生成，选项每次重新打乱。词表缺某类材料时，对应的练习会提示还缺什么，而不是出一张空题。

多份词表怎么管

每次导入一张词表就是一个分组，旧的词表会先收起来，随时能在词表面板里切回来。词表面板还能改名、收起当前词表、把之前所有词表一起放出来做学期复习。导入新词表不会覆盖已有的词和掌握度。

数据存在哪里

词表、移出记录、掌握度和外观偏好都保存在当前浏览器的本地存储里，没有账号，也没有服务器存档。这意味着：

  • 换设备、换浏览器或清理站点数据，词表会丢，建议在词表面板导出 JSON 备份。
  • 同一个人在不同浏览器里是两份独立的数据。
  • 不开闪词的 AI 补全时，词表不会离开这台设备。

常见问题

闪词免费吗？

免费。闪词是纯静态网页，没有账号体系，也没有需要付费解锁的功能。

用闪词要注册或者装 App 吗？

都不用。打开网页就能导入词表开始背，词表和进度只保存在当前浏览器。

我的词表会被上传吗？

不会。词表、移出记录和掌握度都保存在这台设备的浏览器本地存储里，没有服务器存档。页面里复制提示词交给 AI 的补全完全由你手动操作，闪词不会自动上传；进阶补全需要你自己填 DeepSeek API key，只有你发起请求时才会把缺失的字段发给 DeepSeek。

支持 Word、Excel、PDF 吗？

闪词的导入只接受 .json 文件或纯 JSON 数组。Word、Excel、Markdown、PDF 等材料先用页面里的「把其他格式转成 JSON」复制提示词，交给任意 AI 转成 JSON 数组，再粘贴回来导入。

手机上能用吗？

能用，页面适配窄屏。闪词以键盘操作为主，手机上没有外接键盘时，用页面上的按钮也可以完成认词、拼写和练习。

换电脑或清理浏览器数据后词表还在吗？

不在。数据只在当前浏览器里，换设备、换浏览器或清理站点数据都会丢失。词表面板提供 JSON 导出，重要词表建议导出一份备份。

能导出词表吗？

能。词表面板可以导出 JSON，导出的文件可以直接再导入闪词，也可以留作备份。
