# 闪词 3.0

面向临近课堂 quiz 的键盘优先个人词表练习页。一份词表就是一组词：导入后先学这一组，考完先收起，期末可以全部一起复习。

当前首次使用与导入约定见 [导入优先改版记录](docs/flashvocab-import-first-2026-10-27.md)；学习行为见 [重设计规格及验收记录](docs/flashvocab-redesign-2026-10-19.md)。[3.0 重写计划](docs/flashvocab-3-rewrite-plan.md) 保留基础学习契约与历史验收；有变化的部分以当前规格为准。

## 快速开始

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

`./run.sh` 也会在缺少依赖时安装并启动开发服务器。`dist/` 由构建生成并纳入版本控制。

## 怎么学

首次打开是一个三步向导：**1 放入 → 2 核对 → 3 开始**。第一步在「文件 / 粘贴」之间选一个来源：拖入或选择 Word、Excel、CSV、TXT、Markdown、JSON，或者粘贴文字；也能先用内置 24 词体验。第二步只做一件事——核对识别结果：多少个词、多少有中文释义、前五个词长什么样、哪些行没看懂。确认后点「开始背这 N 个词」才进入学习。缺中文释义时，可以复制一段普通文字给任意 AI，再把回复粘回来补全，不需要处理 JSON。

如果导入的是老师发的**填空/匹配 worksheet**（词库和释义分在不同表格里，学生版的单词列是空的），闪词不会假装能配对，而是把第 2 步切换成「这份表要请 AI 读一下」：先复制闪词给的短提示词，再把原文件和提示词一起发给 DeepSeek，最后把回复粘贴回来。回复会被整理成正常词表，然后照常核对、开始背。

有本地词表时直接进入认词。顶部「词表 → 添加新词表」可再加一组，原词表会留着。学习页的认词按 `Q` 认识、`E` 不认识，两种选择都展开释义和例句，再按 `N` 确认并前进。中文在上方，用原英英释义的大字样式；英英释义在下方，用原中文的小字样式。词源与对应概念默认折叠，可手动查看；不再提供 W「模糊」或默认记忆画面。只有选了 Q 才能按 `M` 改判为不认识并前进。`←` 回看，`Delete` / `Backspace` 移出当前词。首次不认识的词通常隔三张卡再出现，本轮加练两次；小词表在轮末补完，加练不重复计分。

设置把练习方式做成三张明确的选择卡：只认词；认词后拼本轮没认出的词；认词后拼全部词。默认只认词。「认识的词直接前进」在「进阶」里，开启后 Q 立即计分并进入下一词；E 仍先看答案再按 N。缺词性时不显示占位，已有注音保留。

拼写用真实输入框，`Enter` 提交；首次空输入或拼错会清空输入，必须重新拼对才能前进，首次错误仍保留。`Esc` 暂停，暂停页 `Enter` 继续，`Space` 先回认词。

认词与拼写分别计算休整：同一模式连续两轮正确后跳过下一整轮，再下一轮返场。返场正确继续休整，失败只释放当前模式；到期词全部返回。轮末停在结算页，显示首次认识、不认识、实际做过的拼写结果及掌握度，`Enter` 开始下一轮。

每词保存连续正确、错误和上次见面时间，已有的历史模糊次数保留兼容。待巩固词先出，未见词居中，渐稳词靠后。连续三次独立轮次或题组首答正确后毕业；加练和拼写不累计知识掌握度。毕业词可以找回，整次找回可撤销。

## 贴近考试的练习

结算页先放继续与换一组词，下面「练一练」用 2×2 网格放四类题及短说明；「词表 → 专项练习」也能进入，练完或退出后回到原学习现场：

- 选择题：优先使用备好的短情景，否则用释义；从当前在学词表现场抽最多三个干扰词，对位词与高混淆词优先。
- 情景题：遮住例句中完整出现的目标词，不猜单词变形。新导入的词表也从认词开始，情景题只在练习入口出现；材料不足会说明原因。
- 填搭配：遮住原例句中的 focus 搭配，词库含当前词表全部不同词，加最多三个实际可用的旧词表、对位或高混淆词。
- 辨析近义词：用贴分界线的情景，从目标词和对应词中二选一；材料可让任意一边成为正确答案。

选项每次现场生成并洗牌，不读取导入的预制答案位置。数字键 `1–9` 选择前九项，其他选项可 Tab 或点击；`N` 下一题。词数或资料不足时按实际可用内容出题或显示补全路径。答错项有红色与「你的选择（错）」标记，正确项有青绿与「正确答案」标记；词库标签统一 Title Case，原数据和判分不变。

## 词表与本地保存

导入成功会新增一组词，之前的词表先收起，词表与历史掌握度保留。「词表」面板可以「练这组」「先收起」，或「全部一起复习」；总复习包括毕业词，但尊重手动移出记录。新增、切换、移出、找回、补全、重置共用一个最近操作 Undo 槽；从导入页撤销会回到原来的学习现场，而不是停在导入页。

词表、移出 ID 和波次元数据保存于 `flashvocab-3-assets-v1`（schema v2），四项掌握度保存于 `flashvocab-mastery-v1`，外观保存于 `flashvocab-theme-v1`。旧 v1 词表迁到日期未知的 W1，ID 与移出记录不变；没有新资产键时兼容读取 `vocab2-learning-v1` 的词表和移出记录，不删除旧键。

刷新重新开始学习队列，清空学习偏好、Undo 和 API key，保留资产、掌握度与外观。重置学习进度会清掌握度、恢复默认偏好，保留词表与移出集合，并可撤销。

JSON 导入的未知字段、源顺序和全部例句均保留。JSON / Markdown 导出排除手动移出词，包含休整和已收起的词；`microScene`、`memorySketch`、`distractors`、`usageTags`、`miniScenario`、`contrastScenarios` 支持两种格式往返。

## 可选 DeepSeek 补全

只在已经导入词表后、想补例句和辨析题时才需要。打开「词表」，展开「用 DeepSeek 补全资料（进阶）」，填写自己的 key 和模型 ID，默认 `deepseek-flash`；[官方接口说明](https://api-docs.deepseek.com/)。key 只在当前页面内存，刷新清空，不写入词表、导出或浏览器存储。导入本身永远不会等待 AI，也不需要 key。

每批最多六词，生成记忆短句与本地 SVG 图所需的结构化物件、高混淆干扰词、用法标签、短情景及双向辨析。缺少的释义、对位和原形例句一并补齐，已有词源、例句和自定义字段保留。小图只使用本地固定图形，不执行 AI 生成的 HTML 或 SVG。已备齐的词不重复请求。记忆图和微画面仍可随词表保存与导出，认词答案不再展示。

生成资料随词表保存，记录服务、模型与实际生成时间。整次成功才应用；失败、取消、超时或补全期间词表变化均保留原词表，不自动重试。真实请求会消耗 DeepSeek API 额度。

## 阅读与操作

首次导入时顶部只留品牌，不显示设置、帮助和 GitHub，避免第一步就分散注意力；有词表后顶部是「词表」、设置齿轮和帮助，不再有 Import / 更多 / 准备页三个平行入口，它们不会在静止后隐藏。Undo 前五秒只在浮动提示中，之后移到顶部，始终只有一个入口；提示到期会将按钮上的键盘焦点交给顶部。词表、设置和帮助各自打开一个专注面板，没有二级 tab；滚动时标题保持可见，Tab 焦点限制在面板内。支持小屏、200% 放大和减少动态效果。

外观默认跟随系统，也可固定亮色或暗色。认词与拼写均先显示中文大字，再显示英英释义小字；沿用系统字体，完整对调原两行的字号、字重、颜色和行距。单击单词复制原始 term；Shift＋单击复制深度理解请求，复制失败时显示可手动复制的全文。

自动发音默认关闭，手动喇叭按钮始终可用。开启后学习动作内同步朗读，优先 Google US English 和自然美式语音，再回退其他英语语音；没有英语语音或播放报错会显示反馈。utterance 保留至结束或报错，React cleanup 不调用全局 cancel。长时间无声时请完整退出浏览器再打开；`speaking=true` 不代表真的出声，验证需同时记录 start、end/error 并实际听音。

## 代码与验证

`src/App.jsx` 组合状态并处理存储、剪贴板、下载、同步发音和补全；`learningAlgorithm.js` 管理评分、队列、休整与 Undo；`ImportView` 负责文件/粘贴、识别预览和 AI 补全入口；`mastery.js`、`waveModel.js`、`questionBuilder.js`、`aiPreparation.js`、`memorySketch.js` 分别管理掌握度、词表、组题、补全和图示验证。组件位于 `src/components/`，副作用 hooks 位于 `src/hooks/`，存储验证位于 `src/storage/`，导入解析与导出位于 `src/utils/deckImport.js`，补全提示词合并位于 `src/utils/importFill.js`，内置词表位于 `src/data/baseDeck.js`。

`npm run check` 执行 ESLint、Node 逻辑/解析/存储测试、Vitest/jsdom UI 行为测试和生产构建。2026-10-27 导入优先改版后为 86 项逻辑、60 项 UI 测试全绿；真实 Chrome 已验证教师风格的 DOCX 表格、XLSX、纯中英对照粘贴、缺释义补全、390px / 280px 窄屏、暗色和 200% CSS 放大，证据在 [`docs/validation-2026-10-27/`](docs/validation-2026-10-27/)。更早的 P0–P2、UIUX 与 2026-10-26 展示回退记录保留为历史。
