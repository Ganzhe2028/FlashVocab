## A. 给 Sol 的执行约束

### 官方依据与本计划的对应设计

已核对 [Sol 模型卡](https://developers.openai.com/api/docs/models/gpt-5.6-sol) 和 [GPT-5.6 官方使用指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.6)。模型卡确认 `gpt-5.6-sol` 支持 `high`；指南强调前端层级与设计判断、主动推进，以及精简提示和明确行动边界。本计划据此只固定产品结果、关键边界和验证证据，让执行者选择局部实现方法。官方材料未证明 Sol 必然过度开发；以下限制是本项目的预防措施。

- 保持用户指定的 Sol high；不自行切换模型、提高推理档位或搭建调用模型的系统。Sol 是开发者，闪词本身不接 AI API。
- 按阶段连续推进，阶段通过后自动进入下一阶段；阶段停止条件表示停止打磨该阶段，不是每一步都等用户批准。
- UIUX 由执行者依据 [D](#design) 落地，不再让用户选择按钮尺寸、布局方案或技术框架。
- 一个主 Agent 顺序完成。这个规模不需要多 Agent 管理、独立研究任务或新的任务线程。
- 新功能、新依赖、新抽象出现前，先找它对应的 [C](#behavior) 行为或 [G](#acceptance) 验收项；找不到就不写。发现未来点子只在最终交付中一句话记录，不建 backlog 系统。
- 只因会改变已定学习规则、无法保全用户文件、必要环境缺失而提问；常规可逆实现自行决定。
- 一个失败经过两次修复仍存在时，先重新定位原因，不继续盲改或扩大重构。能找到新证据就继续修；确实需要外部信息才报告阻塞，不把次数到限当作已完成。
- 不自动 push、开 PR、合并或部署。交付本地可运行的新分支，最终停止条件见 [G](#acceptance)。

不要把整段历史聊天、旧 v0.2 计划和本计划反复拼进提示。读一次相关决策；长任务只保留“当前阶段、已通过验收、未解决问题”三项短记录。

## B. 产品范围：一份词表，一条学习循环

目标用户在 Mac 上，用键盘反复学习一个单元的十几到几十个词。成功是导入后能立刻练，核心循环不需要鼠标，熟词适量休息，忘词及时回来。不是长期课程或大型背词平台。

本版交付：**准备词表 → 辨识 → 拼写 → 辨识**，加上必要的发音、复制、移出/找回、替换/撤销、重置和本地保留词表。整个产品一个页面；准备、学习、拼写暂停、空词表是该页面的状态，不做路由系统。

不做：账户、云同步、多词表库、词表编辑器、长期间隔算法、参数面板、学习报告、排行榜、成就、AI 聊天、图片释义、词典抓取、PWA、原生 App、专门移动端交互、国际化系统、主题切换、组件库展示站。保留小屏基本可用性与键盘可达性，不增加手机产品线。

### 本计划代为确定的有限默认值

这些是解决旧稿待定项的执行选择，不冒充用户早已确认：

- 无本地词表时以 Import 为首要入口；粘贴入口在同一准备区，内置词表只作为次级“试用示例”。有词表时直接用保留的词表开始新一轮。
- 新访问和“重置进度”均回默认偏好：自动发音开、词源折叠；保留词表及手动移出集合。切换浏览器标签、窗口失焦不会重置。
- 手动找回一个词：恢复为两个模式都未练，下一次各模式建队列时加入；从全空状态找回则立即开始辨识。无需搜索、分页、批量操作。
- 管理区只做一个面板，包含词表/帮助、学习设置、已移出列表的分组。没有必要再做独立 Guidebook 页面。

## C. 行为合同

### 辨识与拼写

| 状态/动作 | 必须发生什么 |
| --- | --- |
| 进入辨识单词第一页 | 自动发音一次，只显示首字母小写的普通单词拼写与认识/不认识选项；整词全大写的缩写或特殊词保持原样 |
| 辨识只显示单词，Q / E | 分别暂记认识 / 不认识，显示首字母小写的分音节词形（全大写词保持原样），并第二次发音当前词 |
| 辨识已显示答案，N | 按暂记结果记分，直接进入下一未评分词并发音下一词 |
| 以“认识”进入答案页，M | 改判为不认识，直接进入下一未评分词并发音下一词 |
| 以“不认识”进入答案页 | 只提供 N；M 不响应，避免出现两个含义相同的“下一词” |
| 辨识，← | 回看上一词；重复查看不重复计分；一轮结束须处理完所有未评分词 |
| 辨识，Delete / Backspace | 手动移出当前词，可撤销；拼写输入中的 Backspace 只删字符 |
| 辨识最后一个未评分词完成 | 直接开始拼写；不设资格、最低数量和分流确认页 |
| 拼写输入，Enter | 提交；首次结果计分，显示正确拼写与反馈；拼错后立即清空输入框 |
| 拼写空输入，Enter | 直接按本轮不认识计分，显示与拼错相同的正确单词提示，并等待从头重拼 |
| 拼错后输入 | 在已清空的输入框中从头重打，正确提交后才允许前进；不覆盖首次错误 |
| 已正确/已改正，Enter | 下一题；末题之后直接回辨识 |
| 拼写，Esc | 暂停，清半截输入，保留当前题、已提交结果和队列；暂停页 Enter 继续，Space 回辨识 |
| 暂停后选择辨识 | 开始一轮辨识；原拼写作为单个暂停队列保留，下次进入拼写先继续它，不反复建立多份队列 |

Tab 用标准焦点导航，← 保留回看功能；这是本次 UX 决定，不继续用 Tab 劫持上一词。标准控件、管理输入框、弹层中的键盘操作不被全局快捷键抢走。学习按键忽略 Ctrl/Meta/Alt 组合及长按重复触发；原生拼写输入保留正常编辑、粘贴和焦点行为。使用真实 input，不模拟文字输入器。

### 极简熟悉机制（固定试用值）

- 辨识、拼写独立；每词每模式每轮最多记一次。连续正确两轮后，跳过该模式下一整轮，然后返场。用 `dueRound = scoredRound + 2` 明确定义。
- 返场正确，再休息一整轮；任何一次失败立即清该模式连续成功数，下一轮作为普通词出现，不重置另一模式。
- 改正首次拼错不算新成功。每轮所有到期词返回，无比例上限，无跨模式绑定，无真实日期调度。
- 每次新建队列洗牌；有替代词时避开刚显示的词。暂停恢复不重排。
- 一个模式全部休息时，完成这个空轮并切换另一模式；两个模式都休息时，依次推进空轮直到有题。应以有界纯计算完成，不能做定时轮询、无限循环或显示空白故障页。
- 所有词手动移出时立即进入空词表状态，不再推进轮次。
- 对用户只解释“连续两轮会的词休息一轮，之后回来检查”，不展示两个隐藏池、长历史、算法设置。

### 内容、发音、复制

- 英英释义主读，中文独立下一行；不改变原始词表义项。内置词库已有内容直接保留；只修复实际妨碍阅读的措辞，不全面扩写词条。
- 例句按 `usage` 等已提供的用法标签，每种常用用法取一句；无用法标签时默认第一句。保留其余导入数据用于导出；不在浏览器里自动推断词义，不调用 AI 分类。
- 词源与对应概念默认折叠，用户主动展开。自动发音默认开，可关闭、可手动重播。
- 进入每个辨识词的第一页时自动发音一次，第一次按 Q / E 展开答案时再发音一次；答案页按 N / M 进入下一辨识词时，立即播放下一词。拼写提交后发音，提交前绝不读答案。能由点击或按键触发的播放继续在同一事件中同步调用 Web Speech，并保留播放对象至结束；语音不可用不阻断练习，不加语音服务。
- 单击单词复制原始 `term`；Shift＋单击复制完整 `src/prompts/deep-understanding.md` 加当前词，不翻面、不计分。保留全文；先画面/核心感觉后词根词源的顺序不再修改。
- 悬停才显示上述双动作说明；聚焦单词后原生 Enter/Space 激活复制，Shift 修饰对应完整请求，其他全局学习快捷键不得误触。拼写揭示前没有可复制隐藏答案的入口。
- 本轮不增加 AI 链接跳转或替用户发送请求。剪贴板失败显示可手动复制的内容，不谎报成功。

### 词表与保存

- 保留当前支持的 JSON、Markdown、txt、CSV、DOCX 文件及粘贴导入，JSON/Markdown 导出；不扩展格式。沿用已验证的解析模块和格式测试，避免为“从零”重造 DOCX 解析。
- 解析成功立即替换并开始；失败不改变旧词表、移出集合、进度。只含单词、不含释义时沿用既有解析结果，空字段显示“未提供释义”，帮助区提供现有补全提示词；不生成假释义，也不新增导入向导或补全系统。
- 导出保持源顺序、未知字段及全部例句，排除手动移出词，包含自动休息词；完整原词表仍在本地，可找回移出词。
- 本地长期只需 source deck 和移出 IDs。新访问清学习记录和队列；切到 AI 后返回当前页面保持现场。旧 `vocab2-learning-v1` 只读入这两个必要部分，不迁移旧学习记录。
- 新存储用独立版本 key，避免预览新版本损伤旧页面的数据；先读新 key，不存在再读旧 key，保留旧 key。新旧格式仅做这一条兼容路径，不造迁移框架。保存失败要提示“本次可继续，下次可能不保留”。
- 手动移出、重置、替换提供最近一次的撤销。采用一个明确标注动作名的 Undo 槽：下一个可撤销管理动作覆盖它，普通答题不覆盖；撤销恢复该管理动作前的词表与学习现场。无需无限历史；刷新不保留 Undo。
- 撤销提示位于右上，五秒倒计时，前三秒保持可读、后两秒淡出。之后一级 Undo 仍可随鼠标显现，点一次即可撤销。
- 重置保留词表与手动移出，只重建学习现场和默认偏好；恢复示例属于替换。二者就地说明影响并确认，导入和移出不增加事前确认。

<a id="design"></a>
## D. UIUX 方案：安静的阅读桌面

重新设计布局，保留沙色、青绿、珊瑚的色系联系。旧版的大玻璃卡片、背景圆球、七个胶囊按钮、重复键位说明和大标题不复用。无需 Figma 往返或多套设计竞赛；直接做一套可运行界面。

### 核心构图

以暖白背景和居中的窄阅读列为主体，宽度约 640–720px，两侧充分留白，顶部起点稳定。主内容直接排在页面上，不再套巨大的空卡片。青绿用于进度和成功；珊瑚用于错误或少量重点。系统字体，无网络字体、背景素材和动画依赖。

| 区域 | 布局与层级 |
| --- | --- |
| 词头 | 第一页显示首字母小写的普通词、答案页显示首字母小写的分音节词形；整词全大写的缩写或特殊词保持原样，均为 48–64px；词性和手动发音较小，紧邻词头 |
| 答案 | 英文 24–28px，舒适行距，避免过长单行；中文 16–18px 独立下一行、仍有足够对比度；例句在下方 |
| 阅读帮助 | 词源/对应概念折叠入口在答案下，作为当前词内容，不占页头 |
| 拼写 | 词性与英文释义在同一阅读起点；中文随后，真实输入框 28–36px；提交前不显示词头或发音答案 |
| 核心底栏 | 一处细进度和“当前位置/本轮词数”；单词第一页的 Q / E 是同尺寸、同填充、同阴影强度的平级判断，答案页才使用 N 主要动作与必要的 M 次级动作；保留小键帽提示，无重复操作条 |
| 外围界面 | 轻量品牌、Import、更多、可用时的 Undo/GitHub；全部参与静默隐藏，GitHub 弱化但保留现有链接 |
| 管理面板 | 单个右侧浮层，覆盖式打开但不推动阅读列；打开时用户已退出专注，允许轻遮罩；内部可滚动，Esc 关闭并归还焦点 |

未翻面只显示原词和必要提示，不用数百像素空白占位撑高；翻开后词头位置固定，答案向下展开，核心底栏用稳定桌面位置避免跳动。内容过长时正常页面滚动，不裁切释义；不要为了“首屏容纳全部”压小字号。小屏改自然纵向流，底栏不遮挡正文。

### 静默与反馈

- 鼠标移动/点击显示外围；2.5 秒无指针活动开始隐藏；学习按键立即开始隐藏。视觉淡出约 200ms，布局不变。
- 标题、Import、更多和 Undo 都在隐藏范围。隐藏控件不能截获鼠标或意外焦点；Tab 主动导航时先显现，再按正常次序聚焦。
- 管理面板、折叠详情内的主动操作、焦点处于外围控件时保持其可操作；单词复制也不会触发翻面。
- 五秒 Undo 提示是有限时长的重要操作反馈，不因输入学习键被提前裁掉；底层一级按钮仍按静默规则处理。普通复制只用靠近词的短反馈，不反复抬起整个页头。
- 正确用颜色加文字，错误给正确拼写与“重新输入一次”；短抖动可保留，不循环抖。支持减少动态效果；此时即刻切换而不依赖动画完成回调。

### UX 的明确取舍

首次 Import 优先，不做 onboarding、多页教程或 A/B 两套首屏。关键词位置、英中分行、单一进度、工具退出视线，是本次布局的验收依据。效果达到这些要求且无明显排版问题后停止设计，不再追加“更高级”动效。

## E. 新分支与重写边界

### 开始执行时才做

目标新分支：`codex/flashvocab-3-rewrite`。不直接在 `main` 或当前开发分支重写。

当前工作区有大量未提交内容。先读 status，记录当前 HEAD 和相关文件差异；在独立 worktree 从当前 HEAD 创建目标新分支，原工作区原样保留。把本计划和需要的最新词库、提示词、解析模块及配套测试/配置从当前工作区按明确路径复制到新 worktree，并核对内容；不要默默遗漏未提交的最新版本，不做全目录覆盖或 stash 全部用户工作。若目标分支/路径已存在，先检查是否为本任务，不覆盖未知成果。

worktree 的位置选择环境允许的独立目录；不能因固定路径不可用就改原目录。执行者记录一次新分支、worktree 路径、起点提交和带入文件即可，不新增备份平台。旧版留在原工作区和 Git 历史，不在新应用内维护旧新两套入口。

### 重写什么，保留什么

- **重写**：页面构图、CSS、学习控制和状态组织、键盘与静默交互、管理面板；不把旧 App.jsx 复制过来换类名。
- **保留内容/边界**：内置词库、vocab.md、完整提示词、稳定 ID 含义、导入导出协议、已验证格式解析、现有工具链。保留函数名并不是抄旧 UI。
- **测试**：保留仍符合本计划的行为和解析测试；旧 DOM 选择器或已撤销路由测试按新合同重写。不能为了绿灯把有效测试直接删除。
- **技术**：现有 Vite + React + JavaScript + 普通 CSS。继续使用 ESLint、Node tests、Vitest、现有 CI；不升级包、不转 TypeScript、不加 Tailwind/状态库/路由/动效库。

### 最小代码组织

一个 React `useReducer` 管理学习事件和原子状态变化，纯函数负责评分与队列；存储、发音、剪贴板在副作用边界。视图按学习区和管理区拆，不按每个按钮拆文件。大致为 App、learning、storage、StudyView、SpellView、ManagePanel、两三个必要 hooks、现有 data/utils/prompts；这是责任边界，不是必须建满的目录清单。

队列保存 ID；当前词、进度、休息数量由 state 推导，不保存可推导的副本。管理弹层开关不重建学习队列。随机数和轮次可在纯函数测试中控制。不要用多个 effects 互相纠正学习状态，不引入事件总线、插件接口、通用 repository、策略注册器或为了未来模式预设类层次。

### 阶段二：一次学习内的完整逻辑

完成独立双模式评分、两次成功休息一轮、失败恢复、洗牌、空轮跳过、拼错必改、回看不重复计分、暂停继续。把真实输入与快捷键接到同一组事件。

接入既有导入格式、导出、版本数据读取、替换/移出/找回/重置与一个 Undo 槽，接入发音、双复制、工具面板和静默规则。保持提示词及用户词表数据完整。

**停止条件**：[G 的数据与外围验收](#accept-data) 通过，真实 24 词能完整走一轮辨识与拼写。不得追加词表管理系统、语音供应商或“更智能”的输入解释。

<a id="stage-4"></a>
### 阶段四：交付检查

运行 `npm run check`，真实浏览器操作验证 [G](#acceptance)，核对新旧数据兼容。更新已有 README、Updates、AGENTS 结构说明和两个设计文档的现行部分，使实现、计划和历史状态分清。生成 dist，确认无旧运行入口；只移除属于本次替换的旧文件，不清理用户其他内容。

**停止条件**：最终矩阵全部有证据，无未解释失败；生成最终交付说明后结束。需要用户判断的只剩真实使用感受，不把“你还没体验过”作为继续自行扩展的理由。

## H. 计划的最小可行与冗余审查

### 写作中已主动收缩

- 冗余：四阶段引用同一行为合同与最终矩阵，不另写重复规格；模块清单不强制建满。
- 复核修正：删除了对缺少释义词表新增“补全后才允许练习”的门槛，改为保留导入、就地说明缺失，避免借重写额外增加准备步骤。
- 从零程度：旧页面和控制结构不作新实现模板，但不浪费时间重写经过验证的文件解析与词库内容。
- 停止明确：阶段有退出条件，总验收通过即停止；阻塞不冒充完成，审美改进不无限迭代。
- 仍需真实试用：两轮成功的学习效果、淡出是否舒服、英文释义是否足够易读。这些由用户用下一份词表验证，不是 Sol 在本次开发中自行追加算法/功能的理由。
