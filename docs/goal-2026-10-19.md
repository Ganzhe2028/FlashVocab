给 Codex（macOS 桌面 app，model = 6.1 Sol / gpt-6.1-sol，`features.goals = true` 已开）设置 goal 来执行重设计的重开发环节。本文件自包含，照做即可。

## 用法（Codex macOS app）

1. 打开 Codex app，打开当前工作区里的 `flashvocab`（原文写的是旧 checkout `~/dev/vocab2`，已废弃）
2. 新建一个 chat，把「主目标」那一整段贴进输入框（以 `/goal` 开头），发送
3. 目标进度条会出现在输入框上方，控件支持暂停、恢复、编辑、清除；预算控件里主目标填 `800000`，备选小目标填 `300000`。找不到预算入口就走默认预算，想补设可用 App Server API：`thread/goal/set`，params 带 `objective` 和 `token_budget`
4. 离开电脑前在进度条上暂停目标，回来再恢复；断连状态下的长任务同理
5. 硬性上限（可选）：`~/.codex/config.toml` 加 `[goals]` 一行 `max_goal_token_budget = 1000000`，app 和 CLI 共用这份配置

## 用法（CLI 备选）

1. `cd <当前 flashvocab 目录> && codex`
2. 会话起来后，把「主目标」那一整段贴进去
3. 生命周期管理：`/goal` 单发查看状态，`/goal pause` 暂停，`/goal resume` 继续，`/goal edit` 修改，`/goal clear` 清除

## 行为备注（与官方文档核对过）

- goal 是 thread 级持久状态，目标文本同时充当起始提示词和完成标准
- 只有线程空闲、目标 active、预算未耗尽时才自动续跑；某次续跑一个工具都没调用，下一次自动续跑会被抑制，防空转
- 预算耗尽是软停：当前回合体面收尾，总结进展、阻塞项和下一步；`/goal resume` 接着来，累计进度保留
- 完成必须由模型对照证据审计（改过的文件、跑过的测试、构建产物），不是它觉得完了就算完
- 官方说明页：https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex
