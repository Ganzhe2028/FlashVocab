## 一、理念

### 1. 工具定位

参照不背单词，为个人场景剪裁。

不背的核心拆开来是两层：以单词为单位的状态机，和以天为单位的时间轴。闪词 3.0 目前是单 session 的无状态循环，恰好两层都没有。运营层（酷币、签到、组队、晒成绩）是给留存率打工的，个人工具全是死重，不抄。

### 2. 词汇深度知识

掌握一个词有三个台阶：再认（看到知道什么意思）→ 回忆（不看能想起来）→ 辨析（分得清它和近义词的分界线）。

学校考试的三层题型恰好就是这三个台阶：

- word bank 带多余词 → 语境中回忆加排除干扰
- scenario 配对 MCQ → 给情景选词，应用层再认
- 词义 nuance（描述情景还是人的状态；都是「好」的情景，这个词的好在哪）→ 辨析

工具要练的就是这三层，一层一种题型。

### 3. 精与简的分配

曝光预算跟随判断，不平均分配。

会的词一秒过，模糊的词五秒，不会的词二十秒。简是给会的词的，精是专门为不会的词准备的。一个 wave 刷几天之后大部分词都变成一秒词，session 自然变短。

### 4. 压缩优于铺陈

词源故事和对位辨析是压缩内容，两三行以内，脑子直接有图。完整例句是铺陈内容，读一整句别人的语境换一个词的用法，密度太低。

压缩内容做默认展示，铺陈内容改岗做考题。

### 5. 初见教学，重逢测试

现在的闪词是一台纯测试机器，把第一次接触和第十次复习当成同一种事件，喂一样的内容。难词的痛苦从这里来：第一次见就需要学会，而学习需要上下文，测试给不了。

新 wave 的第一天是学习局，允许慢。之后是刷词局，默认快。

### 6. 个人工具三原则

可逆、最小、无爹味。所有操作可撤销，所有功能能小则小，提醒只能自己设——工具来催，人只会把工具卸了。

## 二、实际情况与 case 分析

### 场景

学期 wave 制。每 1-2 周发布一份 vocab list，随后考其中一部分。一波接一波，不间断。每次只考当波。期末考不考全学期，未知，按「可能考」设计。

### 考试题型（第三次实测确认）

1. word bank：填空，词库带 n 个多余词
2. scenario 识别 / vocab 配对：MCQ，出现频率最高
3. 词义理解：英文释义 in your words，加上 nuance 层的辨析

### case 1：前一次测试，硬背通过

硬背词义能顺滑迁移到 MCQ，说明在当前难度下，recognition 级别的掌握就够用——选项的门槛一半在句子理解，一半在词义辨析，词义这层再认就应付得来。

有一个细节值得盯住：那一次是每天人肉重复撑下来的，调度是他自己做的，工具一分力没出。24 词人肉调度可以，一学期攒五六个 wave，这个成本线性上涨。工具该接走的是他成功里人肉付出的那部分。

### case 2：第三次测试，裸考

题型做得再贴考试，人没来都是零。真正的瓶颈在更上游——那一到两周的窗口里打不打开。

三个设计含义：

- 单次 session 按「可能只来一次」设计，恐慌冲刺二十分钟也要拿到最大收益
- 启动摩擦压到零，打开直接进学习，一个前置步骤都别加
- 提醒功能服务的是出勤。这是 app 化唯一站得住的理由，目前先记着，不急着做

### case 3：例句鸡肋

使用者的原话：不太想读，也读不出词的意思。

完整句子是别人的语境，付整句的阅读成本，换一个词的用法，密度太低。句子里的情景还是随机的，class trip 这种，跟这个词的灵魂没什么关系，读完留不下钩子。

对照之下，deck 里 devise 的词源写法是另一种东西：拉丁语 dividere，「分开」，把整体拆成可执行的步骤——半句话，脑子直接有图。压缩内容才是 encoding 的锚点。

### case 4：词变难了

SAT 级的抽象词，认识和不认识之间有一大片灰色地带。二元 Q/E 会逼他把大量模糊词判成认识，然后它们就再也不会出现。

难词还成对混淆，complicity、negligence、credibility 这种。考试第三层就考这个：分界线在哪。deck 里的 relatedWord 字段已经写了分界线（「devise 重在事先谋划，improvise 当场发挥」），目前折在答案页底下当参考资料。考试在告诉工具：nuance 就是考点本身。

### 现有产品缺陷（dogfood 实测）

- header 静止 2.5 秒自动隐藏，淡入和点击之间存在竞态——「更多」「Import」两个按钮实际点不中，帮助、设置、词表管理、粘贴导入全在那个打不开的抽屉里
- 有了词表之后永远回不到准备页，刷新和新 tab 都直接进学习
- 学完一整轮没有结算，静默跳回辨识第 1 词
- 按 E 之后提示说可以按 M 改判，实际代码里 M 只在按过 Q 时生效——提示、按钮、键盘三处对不上
- 发音按钮的图标长得像「打开外链」；speechSynthesis 只筛 en-US 语音，系统里没有时静默失败
- 拼写全员强制，连全对的词也要重拼一遍，而考试不考拼写

## 三、设计方案

### 3.1 信息架构：wave 生命周期

每个词带 wave 标签，导入时命名（W4、W5……）。

生命周期：当前 wave 在学 → 考完冷藏 → 期末一键复活，全量刷总复习。

导入逻辑从「替换当前词表」改成「新增一波」。旧 wave 的两个用处：期末复活的素材，word bank 题的干扰词水库。

### 3.2 学习循环：两种局

初见局：新 wave 第一天，scenario 先行，允许慢。

刷词局：第二天起，默认极简，按掌握度排序进卡——错过的在前，没见过的居中，稳的垫底。

### 3.3 判断驱动曝光

- Q 认识：一秒过，答案不用展开
- 模糊（新增档）：五秒，看释义和对位一句
- E 不认识：二十秒，词源画面加对位一句，自动展开

现有设置项「词源与对应概念默认折叠」改为折叠状态跟随判断。一行逻辑的事。

按了 E 的词，当 session 内隔几张卡插回来一次，别等下一轮。难词一次曝光留不住，同一次见面里再撞见两回才算编码完成。

### 3.4 E 的二十秒内容规格

词源画面：两三行以内，必须有图。词源天生枯燥或跟现代义脱节的词，AI 补一个微画面。一个词配一图，不多要。

对位一句：relatedWord 的辨析，一句话说清分界线，默认展开。

零完整例句。

### 3.5 题型矩阵

| 题型 | 对应考试层 | 生成方式 |
| --- | --- | --- |
| 辨识（现有，加模糊档） | 基础再认 | 现有逻辑 |
| MCQ 现场组卷 | scenario 配对 | 从当前 wave 抽 3 个干扰项，relatedWord 优先，选项位置每次洗牌 |
| scenario 配对 | scenario 配对 | 例句遮住目标词，四个词选其一 |
| word bank 挖空 | word bank | examples 的 focus 搭配挖空，bank 为当前 wave 全员加 n 个多余词（旧 wave、relatedWord） |
| 对位辨析 | nuance | 贴分界线的 mini scenario，relatedWord 成对二选一，只给有 relatedWord 的词配 |

MCQ 一条铁律：选项绝不预制。预制等于让人背答案位置。现场组卷，同一个词每次见面都是新组合。

### 3.6 掌握度模型（轻量）

每个词记录四个数：连续对几次、错几次、模糊几次、上次什么时候见的。

排序规则见 3.2。连续几轮一次过的词自动毕业，移出主队列，需要时捞回来。

不做完整的 SM-2 算法。1-2 周的冲刺尺度上，优先级排序比精确间隔实用。

### 3.7 拼写降级

默认关闭，或者只拼错词。考试不考拼写，省下来的时间喂给 MCQ 和辨析。

### 3.8 AI 的两个插点

导入时备料，一次性生成，存本地：

- 词源画面或微画面
- 高混淆度的近义干扰词
- 用法标签（描述情景、描述人、描述关系、描述动作）
- 贴分界线的 mini scenario

运行时现场判，只有一个用途：in your words 写英文释义，AI 判对错给反馈。放在辨识答案页，做成可选动作。

API key 自己用就直接调。想分享出去，套一层几行代码的免费 proxy 挡 key。

### 3.9 载体：网站继续，app 不急

隔天调度恰恰是网站最不受限的部分，localStorage 跨天跨年都行。网站真正受限的是主动提醒和跨设备同步。先在这两个点上没卡住之前，维持网站形态。

### 3.10 必修缺陷清单

- 修 quiet 模式点击竞态，header 常驻或点击时同步恢复可交互
- 给学习页加一条回准备页、换词表的活路
- 加轮次结算页，和 3.6 的掌握度数据共用一份
- 修 M 键逻辑或者改提示文案，两边对齐
- 发音按钮换喇叭图标；找不到英文语音时给出可见反馈

### 3.11 迭代路线

- P0：修缺陷清单，加模糊档，折叠跟随判断。最小见效
- P1：MCQ 现场组卷，掌握度排序，结算页
- P2：wave 结构，scenario 题、word bank、对位题，AI 导入备料
- P3：in your words 判分，提醒形态

### P0：顶部按钮点击

顶部工具常驻，quiet 状态只影响周边提示。移除 header 的淡出、位移和禁用点击规则；静止后可直接打开 Import 或更多。`src/App.test.jsx` 覆盖静止后打开两个入口。

<a id="impl-p0-prepare"></a>

### P0：返回准备页

学习页顶部增加「准备页」，可回去导入词表，也可「继续刚才的学习」。切换保留当前题、答案、拼写输入和 Undo。刷新仍直接进学习，不增加启动步骤。UI 和 reducer 测试覆盖返回与恢复。

<a id="impl-p0-summary"></a>

### P0：轮次结算

辨识、拼写完成一轮后停在结算页，显示认识数与首次拼对数；Enter 继续下一轮，也可回准备页。统计直接读取学习状态，重拼正确不会抹掉首次错误。自动跨空轮仍有上限，结算页不会重新调度队列。后续 P1 在这份数据上补掌握度。

<a id="impl-p0-m"></a>

### P0：M 键提示

保留 M 的单向改判：认识改为不认识，并前进。选 E 后的现场提示只显示 N；帮助与快捷键说明写明 M 只在选 Q 后可用。参数化 UI 测试核对两种答案页的提示和按钮。

<a id="impl-p0-speech"></a>

### P0：发音入口与反馈

播放按钮改为喇叭 SVG。保留美式自然语音优先级，缺少时回退其他英语语音；无英语语音或播放报错时，学习页显示原因。发音对象保留到 end/error；cleanup 只移除监听，不取消语音。单元和 UI 测试覆盖回退、缺语音、错误及正常 start/end。

<a id="impl-p0-exposure"></a>

### P0：模糊与内容展开

新增 W「模糊」，不累计正确。Q 后保留原有 N 确认，可略过答案，也可手动查看或 M 改判。W 展示释义和对应概念，E 再自动展开词源；不设等待倒计时。完整例句从辨识答案移出，导入导出仍保留。测试覆盖三档曝光、手动展开、模糊计分与指针后快捷键。

<a id="impl-p0-repeat"></a>

### P0：同轮重现

首次判为不认识的词在本轮再出现两次，通常间隔三张卡；词数不足时在轮末补完。加练不会重复计分或再排加练，首次错误保留，最多每个错词多两次。两种模式的 dueRound 仍各自计算。单词表与六词表测试覆盖间隔、次数和退出，UI 测试覆盖进入拼写前完成加练。

<a id="impl-p0-spell"></a>

### P0：拼写按需开启（3.7）

默认不拼写，辨识结束进入结算。设置提供关闭、只拼错词和模糊词、所有词；保留原拼写输入、纠错、暂停、独立休整与 Undo。已开始的队列不因改设置丢失。测试显式开启旧循环，并新增默认关闭及错词筛选覆盖。

<a id="validation-speech"></a>

### 发音实测

2026-10-20，生产构建在真实 Chrome 使用 Google US English 播放 Vacant，记录到 start 和 end，无 error。Isaac 本轮直接确认「听到了」。静止后顶部按钮实测 opacity 为 1、pointer-events 为 auto，命中测试落在「更多」。

<a id="impl-p1-mcq"></a>

### P1：MCQ 现场组卷

结算页和词表面板可进入选择题，练完显示对错数，也可随时回到原学习现场。以 miniScenario（有则优先）或释义作题干；例句挖空和对位情景由 P2 的独立题型提供。每次进入一道题时，从有效词表现场抽最多三个不同干扰词，词表内的 relatedWord 优先，再洗牌选项。两三词表按实际数量出选项，单词表或缺释义时给出提示。忽略导入的预制 options。测试覆盖干扰池、相关词优先、小词表、重复选项、位置变化、一次计分和键盘完整流程。

<a id="impl-p1-mastery"></a>

### P1：掌握度排序与毕业

每词持久保存连续正确数、错误数、模糊数、上次见面时间，独立于会刷新的学习队列。只记录每轮首次辨识与每组题首次作答；加练和拼写不改知识掌握度。待巩固词先出，未见词居中，已有正确记录的词靠后。同档保留随机性，并优先较弱、较早见过的词。

连续三次独立轮次或题组首答正确后毕业，移出辨识主队列；未毕业词仍遵守原 dueRound。全部毕业有明确页面，可找回毕业词、做选择题或导入新词。找回清零连续正确与辨识休整状态，保留历史错数，可撤销。测试覆盖排序与休整并存、跨轮毕业、找回撤销、四数验证、存储损坏及 UI 加载已存掌握度。

<a id="impl-p1-summary"></a>

### P1：结算与掌握度共用数据

结算分开列出认识、模糊、不认识，以及整份有效词表的待巩固、未见、渐稳、毕业数。只有实际做过拼写才显示拼写统计。首次判断同时更新本轮结果与持久掌握度；回看和同轮加练不重复累计。测试核对模糊数、存储中的四个数与毕业当轮统计。

<a id="impl-p2-wave"></a>

### P2：wave 生命周期

导入可命名，默认 W1、W2 递增。导入成功新增一波，旧词与掌握度保留，旧波次冷藏；当前辨识与 MCQ 只取在学波次。词表面板能单波复活、冷藏、全部复活做期末总复习。总复习找回毕业词，保留历史错数和主动移出记录。操作共用原 Undo，可撤销整次新增或切换。

原资产键升级为 schema v2，增加 waves 元数据；v1 与旧版词表归入 W1，创建日期记为未知，原稳定 ID 与移出记录不变。新导入的同词跨波次独立编号。创建日期来自实际导入事件，页面据此标出初见局或刷词局。冷藏完所有波次后回准备页，可打开已有波次。测试覆盖新增保留、同词隔离、撤销、冷藏与全量复活、移出保留、题库过滤、旧数据迁移及 UI 往返。

<a id="impl-p2-scenario"></a>

### P2：情景题与初见局

情景题从 examples 现场选一句，遮住目标词的全部完整出现位置，再用当前 wave 词池组选择题。目标词只作为其他词的一部分出现、只有变形或没有例句时不猜题。选后给原句与对位反馈；选项仍现场抽取与洗牌。

新 wave 创建当天有可用题时先进入情景学词；例句或干扰词不足则提示后进入辨识，不阻挡使用。退出初见题保留作答掌握度及导入 Undo，辨识按结果排序；旧 wave 与未知日期的旧词表仍直接刷词。测试覆盖遮词边界、多处目标词、缺资料、首日进入与返回排序。

<a id="impl-p2-bank"></a>

### P2：word bank 搭配挖空

按 examples 中原样出现的 focus 挖空，选词后查看完整搭配与原句。每题 bank 放当前在学波次全部不同词，再从未移出的旧波次和 relatedWord 补最多三个额外词；不足时显示实际数量。每次洗牌，前九项可用数字键，其余保留 Tab 和点击。无有效 focus 的词不出这类题。测试覆盖全量当前词、旧波次与对位补词、去重、实际额外数、无效 focus 和 UI 反馈。

<a id="impl-p2-contrast"></a>

### P2：对位辨析

有 relatedWord 且备好 miniScenario 或 contrastScenarios 的词才出二选一。情景不给出分界线，答后显示 relatedWord 辨析；选项每次洗牌。contrastScenarios 可让当前词或对位词分别作正确答案，答案键必须属于这一对词。资料不足时提示补齐，保留当前学习现场。测试覆盖二选一、双向情景、洗牌、非法答案键、缺资料和完整 UI 作答。

<a id="impl-p2-ai"></a>

### P2：DeepSeek 导入备料

实测回修：AI 例句必须含目标词的完整原样出现（大小写可不同），focus 同时包含该词；只有变形的例句保留，但补一条可出题的原形句。记忆画面增加结构化双物件小图，由本地 SVG 绘制；AI 只给物件类型、短标签和关系，不执行生成的 HTML 或 SVG。内置 24 词各有贴词义的小图，其他未备料词显示词源到现代义的概念图。

准备页可选在导入时备料，词表面板也可补齐当前在学波次。原生 fetch 调用 DeepSeek Chat Completions，使用 JSON 输出和非思考模式；每批最多六词，只补缺失资料，已备齐的词不重复请求。不新增运行时依赖。API 规格据 [首次调用](https://api-docs.deepseek.com/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/) 和 [思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 核对。

备料包含文本微画面与结构化 SVG 小图数据（明确作为记忆联想）、高混淆干扰词、用法标签、贴分界线的情景与双向对位题。基础释义、对位和可用例句缺失时一并补齐；保留用户词源、已有例句及自定义字段。AI 干扰词在当前 wave 内优先进入 MCQ，也可补入 word bank。E 优先展示一幅微画面，对应词源仍可手动展开；释义下显示用法标签。

key 仅保存在页面内存；生成资料、模型名和实测生成时间随词表保存。未完成、空响应、词数/索引不符、坏 JSON、内容缺项、HTTP 错误、取消、超时或词库在请求期间变化时，整次不落地，不自动重试。已有波次补料会重开一轮，稳定 ID 变化时对应迁移掌握度和移出记录，整次可撤销。新字段支持 JSON、Markdown 往返；一行一个单词也可导入。

验证包括请求格式、分批进度、一次生成后复用、保留源字段、坏响应与取消、原子更新、ID 迁移、key 不进入存储及 UI 撤销。首次真实请求发现例句仅有变形词，已收紧提示和验证。2026-10-20 修复后使用 devise、improvise 完成真实备料、原形情景题、记忆图、词库题、目标词/对位词作答、独立页面读取与撤销验证；详情见[真实复验](#validation-ai)。测试波次已撤销，原 24 词恢复，页面 key 已清空。

## 导入优先改版（2026-10-27）

用户反馈「不知道怎么用」「自己输入中英翻译无法识别」「Word 单词表 + 提示词 + JSON + 粘贴」无法完成，并明确要求交互优先于文字指引。本轮把首次使用从「准备页 + 帮助面板」改为三步向导：**1 放入 → 2 核对 → 3 开始**。第 1 步在「文件 / 粘贴」tab 中二选一，文件读取时显示「正在识别…」；第 2 步只核对词数、中文释义数和前五个词，整屏只有一个主按钮；缺中文释义时再用普通文字让 AI 补全。首次打开隐藏设置/帮助/GitHub 等全局导航，只留品牌。完整约定、解析规则、移除项与验收证据见[导入优先改版记录](flashvocab-import-first-2026-10-27.md)。

关键变化：

- 顶部不再有准备页 / Import / 更多三个平行入口；改为词表、设置、帮助三个专注面板。首次使用只显示品牌。
- 导入页改成三步向导，每步只保留一个主动作；文件读取有「正在识别…」状态；第 2 步只核对词数和前五个词，不再展示字段胶囊、命名或次按钮。
